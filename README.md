# 펜타토닉 손가락 운동기 (PentatonicMaster)

일렉기타 솔로에서 자주 쓰는 펜타토닉 스케일 운지 패턴을 **컴퓨터 키보드로 미리 연습**하면서 손가락을 훈련하는 웹앱입니다.

## 연습 방법

- 키보드 손가락이 기타 운지 손가락에 1:1로 대응합니다.
  - 왼손: `F` = 검지(1), `D` = 중지(2), `S` = 약지(3), `A` = 새끼(4)
  - 설정에서 오른손(`J K L ;`)으로 바꿀 수 있습니다.
- 지판에서 지금 칠 음(주황색)과 다음 음(점선)을 보여주고, 아래 테이프에 앞으로 칠 손가락 순서가 나옵니다.
- 한글 입력 상태에서도 동작합니다 (물리 키 위치 기준).

### 모드

- **자유 연습**: 키를 누르면 바로 시작합니다. 맞는 손가락을 눌러야 다음 음으로 넘어가고, 초당 음 수와 16분음표 환산 BPM을 보여줍니다.
- **메트로놈**: `Space`로 시작하면 4박 카운트 후 박자에 맞춰 칩니다. 퍼펙트/굿/놓침/틀림과 평균 타이밍 오차를 보여줍니다. "실수 없이 한 바퀴 돌면 +4 BPM"을 켜면 점점 빨라집니다.

### 지원 범위

- 12개 키, 마이너/메이저 펜타토닉, 박스 포지션 1~5
- 패턴: 상행, 하행, 왕복, 3음/4음 시퀀스, 3도 건너뛰기, 2줄 롤 하행, 6음 하행 런

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm test         # 단위 테스트 (vitest)
npm run build    # dist/ 에 정적 사이트 빌드
```

Vite + React + TypeScript로 만든 정적 사이트라 서버 없이 어디든 올릴 수 있습니다 (`base: './'`).
