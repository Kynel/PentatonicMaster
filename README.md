# 손가락 운동기 (PentatonicMaster)

기타 솔로에서 손가락이 움직이는 순서를 **컴퓨터 키보드로 미리 쳐서** 손가락을 훈련하는 웹앱입니다.
`A S D F` = 1 2 3 4번 손가락(검지, 중지, 약지, 새끼). 설정에서 오른손 `J K L ;`로 바꿀 수 있습니다.

## 연습 흐름

1. 왼쪽 목록에서 연습을 고릅니다.
   - **손가락 독립 드릴**: 1234, 교차, 트릴(1-3, 1-4, 2-4, 3-4) 등
   - **펜타토닉 패턴**: 상행/하행/3음·4음 시퀀스 등, 박스 1~5 선택
   - **솔로 릭**: 록/블루스/J-rock 스타일 연습 릭 (이 앱용으로 새로 만든 프레이즈)
   - **내 패턴**: `sfdf sfsf dfsf`처럼 손가락 순서를 직접 적어 저장
2. **익히기**: 박자 없이 순서만 익힙니다. 손가락마다 색이 다르고, 틀리면 맞는 키를 칠 때까지 기다립니다.
3. **템포**: 리듬게임처럼 네 줄 레인에서 음이 판정선으로 내려옵니다. 메트로놈에 맞춰 칩니다.
   판정은 가장 가까운 음 기준이라 한 번 놓쳐도 다음 음부터 바로 회복됩니다. 아래 게이지에 빠름/느림이 찍힙니다.
   **속도 사다리**를 켜면 실수 없는 바퀴마다 BPM +5, 틀리면 -5.
4. 정해진 반복이 끝나면 **결과**가 나옵니다: 정확도, 평균 타이밍(서두름/밀림), 흔들림, 자주 틀린 구간, 다음에 칠 BPM 제안.
   연습마다 최고 기록(정확도 95% 이상)과 BPM이 저장됩니다.

단축키: `Space` 시작/그만, `Esc` 그만, 결과 화면에서 `Space` 제안대로 다시, `Enter` 같은 설정으로 다시.

## 개발

```bash
npm install
npm run dev      # 개발 서버
npm test         # 단위 테스트 (vitest)
npm run build    # dist/ 에 정적 사이트 빌드
```

Vite + React + TypeScript 정적 사이트입니다. Vercel에서 저장소를 Import 하면 설정 없이 배포됩니다.

- `src/engine/`: 연습 엔진 (템포 세션 판정, 익히기 세션, 결과 계산). React와 무관하고 테스트가 있습니다.
- `src/exercises.ts`: 연습 목록
- `src/music/`: 펜타토닉 박스, 패턴, 릭과 탭/키 순서 파서
- `src/ui/`: 화면 컴포넌트 (하이웨이 캔버스, 키 줄, 결과 카드 등)
